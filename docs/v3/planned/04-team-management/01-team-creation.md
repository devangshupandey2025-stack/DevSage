# Team Creation

> `POST /api/v1/hackathons/:slug/teams` — Organizer or co-organizer creates a team.

## Endpoint

```
POST /api/v1/hackathons/:slug/teams
Auth: authMiddleware + requireRole('co_organizer')
State: draft or active only
```

## Request Body

```ts
const createTeamSchema = z.object({
  name: z.string().min(2).max(50),
  track_id: z.string().uuid().optional(),  // if multi-track hackathon
});
```

## Implementation

```ts
// 1. Check hackathon is in draft or active state
// 2. Check max_teams limit not exceeded
// 3. If track_id provided, verify track exists and has capacity
// 4. Generate invite code (8-char alphanumeric)
// 5. Insert team row
// 6. Audit: team.created

const inviteCode = generateInviteCode(); // crypto.randomUUID().slice(0, 8)

await db.insert(teams).values({
  id: crypto.randomUUID(),
  hackathon_id: hackathonId,
  name: body.name,
  invite_code: inviteCode,
  track_id: body.track_id ?? null,
  status: 'forming',  // forming → ready → submitted
  created_at: new Date().toISOString(),
  updated_at: new Date().toISOString(),
});
```

## Invite Code

- 8-character alphanumeric string
- Unique per hackathon
- Used by participants to join: `POST /api/v1/hackathons/:slug/teams/join`
- Can be regenerated by team lead or organizer

## Team Statuses

| Status | Meaning |
|--------|---------|
| `forming` | Team created, members joining |
| `ready` | GitHub repo linked, meets min team size |
| `submitted` | At least one submission captured |

## Error Codes

| Code | HTTP | When |
|------|------|------|
| `HACKATHON_NOT_ACTIVE` | 400 | Hackathon not in draft/active state |
| `MAX_TEAMS_REACHED` | 400 | Hackathon team limit exceeded |
| `TRACK_NOT_FOUND` | 404 | Invalid track_id |
| `TRACK_FULL` | 400 | Track's max_teams reached |
| `TEAM_NAME_TAKEN` | 409 | Name already used in this hackathon |
