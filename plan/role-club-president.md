# Club President(s) — Workspace Owner User Flow

> Role: Workspace Owner | Scope: Workspace | App: `platform.devsage.org` | Max: 2 per workspace

---

## Who

Club president(s). Primary responsibility is billing and plan selection. Has full workspace access but delegates day-to-day operations to Managers.

---

## Flow

### 1. Onboarding

1. Receive invite email from DevSage Platform Admin
2. Click invite link → land on `platform.devsage.org`
3. Sign up or log in (Google OAuth or email/password with OTP 2FA)
4. Accept workspace invite → now has access to the workspace

### 2. Workspace Setup

1. Log into Platform
2. Select billing plan for the workspace (₹3,999–₹9,999 semester-based)
3. Invite club VPs as **Workspace Managers**
4. Managers receive invite, sign up / log in, accept invite
5. Primary job is done — managers take over operations

### 3. Ongoing Access

Owner retains **full access** across the workspace:

- View analytics across all hackathons
- Configure hackathons (can, but delegates to Managers/Event Leads)
- Submit hackathon requests (can, but delegates to Managers)
- Invite event leads (can, but delegates to Managers)
- Monitor teams, submissions, scoring
- Transition hackathon states, publish results

Owner's day-to-day involvement is minimal — the role exists primarily for billing accountability and institutional oversight.

## Permissions

| Action | Access |
|--------|--------|
| Billing & plan | ✅ Primary responsibility |
| Invite managers | ✅ Primary responsibility |
| Submit hackathon request | ✅* |
| Invite event leads | ✅* |
| View hackathon analytics | ✅ |
| Configure hackathon | ✅* |
| Manage rounds & rubric | ✅* |
| Invite judges (invite link or create account) | ✅* |
| Transition hackathon state | ✅* |
| Monitor teams & submissions | ✅* |
| Assign judges to submissions | ✅* |
| Publish results | ✅* |
| Select advancing teams (elimination rounds) | ✅* |

> **✅*** = Has full access but is not expected to perform these day-to-day. Delegates to Managers and Event Leads.

---

## Key Constraints

- Maximum 2 Workspace Owners per workspace
- Cannot create workspaces (only Platform Admin can)
- Cannot manage the platform admin list
- Cannot approve/reject hackathon requests (only Platform Admin can)
