# 11 — API Design

> REST API conventions, response envelope, error codes, rate limiting, and route table.

## URL Structure

```
https://api.devsage.org/api/v1/hackathons/{slug}/...
                       └─ prefix  └─ resource └─ slug-based addressing
```

All hackathon resources are addressed by slug (not UUID) in URLs.

## Response Envelope

Every response follows this shape:

```ts
// Success
{ ok: true, data: T, meta?: { etag?, timestamp?, total?, limit?, offset?, has_more? } }

// Error
{ ok: false, error: { code: string, message: string, details?: unknown } }
```

## App Setup

The API Worker uses Hono with typed bindings. Set up the root app and mount route modules:

```ts
import { Hono } from 'hono';
import { cors } from 'hono/cors';
import type { Env } from './types/env.js';

const app = new Hono<{ Bindings: Env }>();

// CORS — must be first middleware
app.use('*', cors({
  origin: ['https://devsage.org', 'http://localhost:5173'],
  allowMethods: ['GET', 'POST', 'PATCH', 'DELETE', 'OPTIONS'],
  allowHeaders: ['Content-Type', 'Authorization'],
  exposeHeaders: ['ETag', 'X-Request-Id', 'X-RateLimit-Limit', 'X-RateLimit-Remaining', 'X-RateLimit-Reset'],
  credentials: true,
  maxAge: 86400,
}));

// Mount route modules
app.route('/auth', authRoutes);
app.route('/api/v1/workspaces', workspaceRoutes);
app.route('/api/v1/hackathons', hackathonRoutes);

export default app;
```

> **Note:** `Env` is auto-generated by `npx wrangler types` — see [12-infrastructure/01-cloudflare-bindings.md](../12-infrastructure/01-cloudflare-bindings.md).
